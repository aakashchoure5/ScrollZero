# ScrollZero

Premium startup website for ScrollZero — **Reclaim Your Attention.**

## Stack

- Next.js 16 (App Router, TypeScript)
- Tailwind CSS
- Framer Motion
- Shadcn-style UI primitives (Radix + CVA)
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run lint
npm run build
```
